## 2. Project Title

Student Grade Calculator 

---

## 3. Project Description

This program is a program to calculate a student's final grade.

---

## 4. Objectives

This project is designed to apply the following programming concepts:

- Variables
- Data types
- Operators
- Conditional statements
- Loops
- Algorithms
- JavaScript

---

## 5. Input

The program receives:

- Assignment Grade
- Quizz Score
- Midterm Exam Score
- Final Semester Exam Grade

---

## 6. Process

The program uses the following score weights:
| No. | Component | Weight | 
|---|---|---|
| 1 | Assignment Grade | 20% | 
| 2 | Quizz Score | 20% | 
| 3 | MidTerm Exam Score | 30% | 
| 4 | Final Semester Exam Score| 30% | 

Then, the program must calculate the final score and determine the student's letter grade. The criteria are as follows:
| No. | Final Grade | Grade | 
|---|---|---|
| 1 | 80 - 100 | A | 
| 2 | 70 - 79 | B | 
| 3 | 60 - 69 | C | 
| 4 | 50 - 59 | D | 
| 5 | > 50 | E | 

---

## 7. Output

The program displays:

- Assignment Grade
- Quizz Score
- MidTerm Exam Score
- Final Semester Exam Score
- Final Student Grade in numerical form
- Final Student Grade in letter form
